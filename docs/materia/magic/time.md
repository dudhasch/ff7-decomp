# Time Materia

> *Equips "Time" magic*

## Overview

ATB manipulation. Haste speeds an ally's gauge, Slow halves an enemy's, and Stop freezes it entirely. Only outright immunity prevents Slow, making it one of the most reliable debuffs in the game.
