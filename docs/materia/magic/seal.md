# Seal Materia

> *Equips "Seal" magic*

## Overview

Disabling magic. Sleepel puts a target to sleep (broken by any damage); Silence blocks the target's Magic command, which shuts down many spellcasting enemies outright. Equipping Seal also confers the Sleep and Silence statuses to its Added Effect / Elemental pairings.
