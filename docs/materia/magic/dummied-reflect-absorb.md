# リフアブ (Rifuabu) - "Reflect Absorb" (dummied)

> **Unused.** This Materia exists in the game data but is never obtainable; it has no price and no location.

## Overview

An unused Materia granting no spell at level 1 and Wall at level 2. The name suggests an intended reflect-and-absorb mechanic that was never implemented.

## In-game description (unused)

ウォールの魔法が使えるようになる。 (*Woru no maho ga tsukaeru yo ni naru.* - lit. "You become able to use Wall magic.")
