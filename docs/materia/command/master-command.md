# Master Command Materia

> *Equips some commands*

## Overview

Grants eight commands in a single slot. Note it does *not* include Slash-All, Double Cut, W-Magic, W-Summon, W-Item or Enemy Skill. Subject of the Master Command and Support Materia glitch: a Support Materia linked to it applies to every command the character has, including plain Attack and Item.

## At a glance

| | |
| --- | --- |
| **Category** | [Command Materia](README.md) (yellow) |
| **Element** | Hidden (Command Materia have no element of their own) |
| **Status** | None - Command Materia carry no status traits for Added Effect |
| **Max level** | 1 |
| **AP to master** | 0 |
| **Buy price** | 1 gil |

## Stat changes

None.

## Levels

| Level | Command | AP to reach |

## How to obtain

- Cosmo Canyon - bring mastered Steal, Sense, Throw, Morph, Deathblow, Manipulate and Mime to the yellow Huge Materia
- Kalm traveler
