# Steal Materia

> *Equips "Steal" command*

## Overview

Steal takes an item from an enemy without dealing damage; Mug, at level 2, attacks and steals in the same action. Many rare items exist only as steals.

## At a glance

| | |
| --- | --- |
| **Category** | [Command Materia](README.md) (yellow) |
| **Element** | Hidden (Command Materia have no element of their own) |
| **Status** | None - Command Materia carry no status traits for Added Effect |
| **Max level** | 3 |
| **AP to master** | 50,000 |
| **Buy price** | 1,200 gil |
