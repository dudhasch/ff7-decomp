# Command Materia (yellow)

Adds a battle command that is neither Magic nor Summon. Command Materia carry no status traits for Added Effect, and give the Hidden element when paired with Elemental.

| Materia | Commands | Stat changes | AP to master |
| --- | --- | --- | --- |
| [Slash-All](slash-all.md) | Slash-All, Flash | None | 150,000 |
| [Double Cut](double-cut.md) | 2x-Cut, 4x-Cut | Dexterity +2 | 150,000 |
| [W-Magic](w-magic.md) | W-Magic | None | 250,000 |
| [W-Summon](w-summon.md) | W-Sum. | None | 250,000 |
| [W-Item](w-item.md) | W-Item | None | 250,000 |
| [Steal](steal.md) | Steal, Mug | Dexterity +2 | 50,000 |
| [Sense](sense.md) | Sense | None | 40,000 |
| [Throw](throw.md) | Throw, Coin | Vitality +1 | 60,000 |
| [Morph](morph.md) | Morph | None | 100,000 |
| [Deathblow](deathblow.md) | D.blow | Luck +1 | 40,000 |
| [Manipulate](manipulate.md) | Manip. | None | 40,000 |
| [Mime](mime.md) | Mime | None | 100,000 |
| [Enemy Skill](enemy-skill.md) | E.Skill | None | Cannot be mastered |
| [Master Command](master-command.md) | Steal; Sense; Coin; Throw; Morph; D.blow; Manip.; Mime | None | 0 |
