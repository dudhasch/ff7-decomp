# Leviathan Materia

> *Summons Leviathan*

## Overview

The game's only Water-elemental summon, and the only practical way to add Water to a weapon through Elemental Materia.

## At a glance

| | |
| --- | --- |
| **Category** | [Summon Materia](README.md) (red) |
| **Element** | Water |
| **Status** | -- |
| **AP to master** | 100,000 |
| **Castings per battle** | 1 per star (5 at master) |
| **Sell price** | 1 gil - Summon Materia can never be bought, and always sell for 1 gil regardless of level |

- Defeat Godo in Wutai (the Pagoda of the Five Mighty Gods).
