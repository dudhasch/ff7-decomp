# Master Summon Materia

> *All Summoned monsters summoned*

## Overview

Grants the whole Summon skillset with no stat changes and, uniquely, **no cap on castings per battle** - the only limit is available MP. Building it consumes one mastered copy of every Summon Materia.

## At a glance

| | |
| --- | --- |
| **Category** | [Summon Materia](README.md) (red) |
| **Element** | Hidden |
| **Status** | -- |
| **AP to master** | - |
| **Castings per battle** | **Unlimited** |
| **Sell price** | 1 gil - Summon Materia can never be bought, and always sell for 1 gil regardless of level |

## Stat changes

None - Master Summon applies no stat penalty or bonus.

## Summons

Grants every summon command. See the [summon ability index](../../spells/summon/).

## How to obtain

- Cosmo Canyon - the red Huge Materia in Bugenhagen's observatory, granted once the party holds all sixteen mastered Summon Materia.
- Give the Earth Harp to the Kalm traveler after defeating Emerald Weapon.
