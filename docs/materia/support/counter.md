# Counter Materia

## Overview

Counters incoming attacks using the linked *command*. Note the chocobo-racing prize called "Counter" is actually Counter Attack, an Independent Materia - a different thing. Counter linked to Mime, or to Master Command, produces some of the strongest automatic setups in the game.

## At a glance

| | |
| --- | --- |
| **Category** | [Support Materia](README.md) (blue) |
| **Max level** | 5 |
| **AP to master** | 100,000 |
| **Stat changes** | None - Support Materia never change stats |

## Links to

Steal, Sense, Throw, Morph, Deathblow, Manipulate, Mime, Master Command

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | 30% chance of countering an attack with the linked Materia. | 0 |
| 2 | 40% chance. | 20,000 |
| 3 | 60% chance. | 40,000 |
| 4 | 80% chance. | 60,000 |
| 5 | 100% chance. | 100,000 |

## How to obtain

- Northern Cave

## Note

Because of the *Master Command and Support Materia* glitch, a Support Materia linked to [Master Command](../command/master-command.md) applies its effect to every command the character can use - including plain Attack and Item.
