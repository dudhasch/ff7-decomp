# MP Turbo Materia

## Overview

A straight damage-for-MP trade. Because the damage cap is 9999 per hit, MP Turbo is most valuable on spells that fall short of the cap rather than on ones already hitting it.

## At a glance

| | |
| --- | --- |
| **Category** | [Support Materia](README.md) (blue) |
| **Max level** | 5 |
| **AP to master** | 120,000 |
| **Stat changes** | None - Support Materia never change stats |

## Links to

All Magic and Summon Materia

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Linked Magic or Summon deals 10% more damage and costs 10% more MP. | 0 |
| 2 | 20% more damage, 20% more MP. | 10,000 |
| 3 | 30% more damage, 30% more MP. | 30,000 |
| 4 | 40% more damage, 40% more MP. | 60,000 |
| 5 | 50% more damage, 50% more MP. | 120,000 |

## How to obtain

- Whirlwind Maze. **Missable** if not picked up.

## Note

Because of the *Master Command and Support Materia* glitch, a Support Materia linked to [Master Command](../command/master-command.md) applies its effect to every command the character can use - including plain Attack and Item.
