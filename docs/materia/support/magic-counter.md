# Magic Counter Materia

## Overview

Counter's magical twin: it retaliates by casting the linked spell or summon. Mastering it costs 300,000 AP, among the steepest in the game.

## At a glance

| | |
| --- | --- |
| **Category** | [Support Materia](README.md) (blue) |
| **Max level** | 5 |
| **AP to master** | 300,000 |
| **Stat changes** | None - Support Materia never change stats |

## Links to

All Magic and Summon Materia

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | 30% chance of countering an attack with the linked Magic Materia. | 0 |
| 2 | 40% chance. | 20,000 |
| 3 | 60% chance. | 40,000 |
| 4 | 80% chance. | 80,000 |
| 5 | 100% chance. | 300,000 |

## How to obtain

- Northern Cave
- Chocobo race prize

## Note

Because of the *Master Command and Support Materia* glitch, a Support Materia linked to [Master Command](../command/master-command.md) applies its effect to every command the character can use - including plain Attack and Item.
