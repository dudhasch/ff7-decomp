# Added Cut Materia

## Overview

Adds a free physical hit after the linked Materia resolves. Equipping several Added Cuts to the same Materia does **not** stack - only one follow-up occurs.

## At a glance

| | |
| --- | --- |
| **Category** | [Support Materia](README.md) (blue) |
| **Max level** | 1 |
| **AP to master** | 200,000 |
| **Stat changes** | None - Support Materia never change stats |

## Links to

All Magic and Summon Materia; Steal, Sense, Throw, Morph, Deathblow, Manipulate, Mime, Master Command

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Follows up use of the linked Materia with a physical attack, against the same target as the previous action. | 200,000 |

## How to obtain

- Great Glacier

## Note

Because of the *Master Command and Support Materia* glitch, a Support Materia linked to [Master Command](../command/master-command.md) applies its effect to every command the character can use - including plain Attack and Item.
