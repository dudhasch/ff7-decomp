# Underwater Materia

## Overview

A single-purpose Materia: without it, Emerald Weapon kills the party when its timer expires. It gains AP but can never level up or grow into a new Materia - it can technically be mastered, but only by accumulating exactly 16,777,215 AP. Barret's Missing Score weapon, whose damage scales with equipped AP, always treats this Materia as holding 0 AP.

- Kalm traveler - trade the Guide Book. **Missable** if the Morph Materia is missed, since the Guide Book is a Morph-only item.
