# Luck Plus Materia

## Overview

Luck governs critical-hit rate and the chance of dodging or landing instant-death effects, making this quietly one of the stronger stat Materia.

## At a glance

| | |
| --- | --- |
| **Category** | [Independent Materia](README.md) (purple) |
| **Max level** | 5 |
| **AP to master** | 100,000 |

## Stat changes

None.

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Increases Luck by 10%. | 0 |
| 2 | By 20%. | 15,000 |
| 3 | By 30%. | 30,000 |
| 4 | By 40%. | 60,000 |
| Master | By 50%. | 100,000 |

## How to obtain

- Temple of the Ancients. **Missable** if not picked up.
