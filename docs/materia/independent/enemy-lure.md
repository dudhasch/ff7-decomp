# Enemy Lure Materia

## Overview

The only Independent Materia with a stat penalty. Used deliberately for AP and Gil farming.

## At a glance

| | |
| --- | --- |
| **Category** | [Independent Materia](README.md) (purple) |
| **Max level** | 3 |
| **AP to master** | 50,000 |

## Stat changes

| Stat | Change |
| --- | --- |
| Luck | -1 |

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Increases the random encounter rate by 43.75%. | 0 |
| 2 | Increases it by 87.5%. | 10,000 |
| Master | 87.5%; stacks with additional Enemy Lure Materia up to 200%. On the world map the rate is doubled again above 100%, for a maximum of 400%. | 50,000 |

## How to obtain

- Battle Square prize
