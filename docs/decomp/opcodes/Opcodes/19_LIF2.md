- Opcode: **0x19**
- Short name: **LIF2**
- Handler: `OpcodeFuncLif2u`
- Status: verified -- compiled from C in a green build
- Length: **9** bytes (`PC_INC(9)`)
- The in-game debugger prints 8 argument byte(s); this saturates at 8 and is not the instruction length.

#### Memory layout

| 0x19 | *arg7* | *?* | *?* | *?* | *?* | *?* | *?* |
|------|--------|-----|-----|-----|-----|-----|-----|

#### Arguments
