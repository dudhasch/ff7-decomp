- Short name: **CHMST**
- Handler: `OpcodeFuncChmst`
- Status: verified -- compiled from C in a green build
- Length: **3** bytes (`PC_INC(3)`)
- The in-game debugger prints 2 argument byte(s); this saturates at 8 and is not the instruction length.
