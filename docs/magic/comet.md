# Comet Materia

> *Equips "Comet" magic*

## Overview

Non-elemental damage that cannot be reflected, so it works against enemies and bosses that carry Reflect. Comet hits one target hard; Comet2 fires four weaker hits at random targets, which pairs poorly with All but well against a single surviving enemy.
