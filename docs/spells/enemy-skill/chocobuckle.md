# Chocobuckle

> *Non-elemental damage on any one opponent*

## Effect

Damage to one target equal to the number of times the party has fled from battle.

## Details

| | |
| --- | --- |
| **Granted by** | [Enemy Skill Materia](../../materia/command/enemy-skill.md) |
| **MP cost** | 3 |
| **Spell power** | 0 |
| **Type** | Physical |
| **Reflectable** | No |
| **Permanently missable** | **Yes** |

## How to learn it

Learned from: **Chocobo**

A character wearing an Enemy Skill Materia learns the skill the moment they are successfully targeted by it - whether or not they survive. The skill is lost if the party escapes the battle, and skills can never be learned in the Gold Saucer Battle Square.

> **Missable.** This skill can be permanently lost - see the notes on the [Enemy Skill Materia](../../materia/command/enemy-skill.md) page.
