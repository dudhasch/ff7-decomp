# White Wind

> *Restores HP and status to every ally*

## Effect

Restores HP equal to the caster's current HP and cures Sleep, Poison, Confusion, Silence, Slow, Stop, Frog, Small, Slow-numb, Petrify, Berserk, Paralyzed, Darkness, Death Force and Resist on the whole target party. Cannot be reflected.

## Details

| | |
| --- | --- |
| **Granted by** | [Enemy Skill Materia](../../materia/command/enemy-skill.md) |
| **MP cost** | 34 |
| **Spell power** | 0 |
| **Type** | Physical |
| **Reflectable** | No |
| **Permanently missable** | No |

## How to learn it

Learned from: **Zemzelett (Manipulate only), Wind Wing (Confuse only)**

A character wearing an Enemy Skill Materia learns the skill the moment they are successfully targeted by it - whether or not they survive. The skill is lost if the party escapes the battle, and skills can never be learned in the Gold Saucer Battle Square.
