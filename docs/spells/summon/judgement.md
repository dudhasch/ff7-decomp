# Judgement

> *Causes Holy Magic damage on all opponents*

## Effect

Holy-elemental damage to all enemies.

## Details

| | |
| --- | --- |
| **Summon command** | Alexander |
| **Granted by** | [Alexander Materia](../../materia/summon/alexander.md) |
| **MP cost** | 120 |
| **Spell power** | 120 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
