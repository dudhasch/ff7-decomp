# Disintegration

> *Causes [Fire/Ice/Lightning/Earth] magic damage*

## Effect

High Fire, Ice, Lightning and Earth damage to all enemies. Ignores Magic Defense.

## Details

| | |
| --- | --- |
| **Summon command** | Typhon |
| **Granted by** | [Typhon Materia](../../materia/summon/typhon.md) |
| **MP cost** | 160 |
| **Spell power** | 110 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
