# Tera Flare

> *Unblockable Non-Elemental attack*

## Effect

Heavy non-elemental damage to all enemies. Ignores Magic Defense.

## Details

| | |
| --- | --- |
| **Summon command** | Bahamut ZERO |
| **Granted by** | [Bahamut ZERO Materia](../../materia/summon/bahamut-zero.md) |
| **MP cost** | 180 |
| **Spell power** | 120 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
