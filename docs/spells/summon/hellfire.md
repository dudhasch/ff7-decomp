# Hellfire

> *Fire magic damage on all opponents*

## Effect

Fire-elemental damage to all enemies.

## Details

| | |
| --- | --- |
| **Summon command** | Ifrit |
| **Granted by** | [Ifrit Materia](../../materia/summon/ifrit.md) |
| **MP cost** | 34 |
| **Spell power** | 27 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
