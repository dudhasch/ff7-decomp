Paralysis is a state that Cloud (or the party leader) will enter into under certain conditions, such as dialogue screens. This is tracked by a single memory value found at RAM address 09AC26 with the following possible values:

0 = Paralysis Inactive

1 = Paralysis Active

When paralysis is active, the player is unable to move. This condition clears when the script triggering paralysis (such as a conversation) is completed. However, it is possible under certain circumstances to negate the effects of paralysis or cancel it out through the use of a Paralysis Dodge. This often, but not always, involves triggering two conversations at the same time. A Paralysis Dodge is sometimes a useful time-saving strategy that allows the player to clear two conversations at once or lets them move while finishing a conversation.
