The Vincent Mug Glitch is a trick that allows the player to skip battle animations with Vincent's mug animation. Damage will still be calculated and dealt as normal, but the animation will not play.

## Execution

In order to perform the glitch, Vincent must be equipped with a leveled up Steal materia, and one of the following weapons:

  * Shortbarrel
  * Winchester
  * Long Barrel R
  * Sniper CR
  * Death Penalty

With this setup, Vincent must use Mug immediately before the animation that the player wishes to be skipped.

## Use in runs

This glitch is used in runs that recruit Vincent in order to skip long animations, like Knights of the Round or [Safer Sephiroth](/index.php?title=Safer_Sephiroth&action=edit&redlink=1 "Safer Sephiroth \(page does not exist\)")'s death animation.
