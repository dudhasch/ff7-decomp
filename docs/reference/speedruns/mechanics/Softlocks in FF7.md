Here is a list of known softlocks in Final Fantasy VII.

### Skip/Manip Softlocks

  *   *   * [**Bar Skip**](/index.php/Bar_Skip "Bar Skip") can cause Cloud to get stuck, resulting in a softlock if performed incorrectly.
  * **Sector 5 Church** : If you perform [Guard Skip](/index.php/Guard_Skip "Guard Skip") and then attempt to visit the church, there will be an error with the cutscene playback and Cloud will get stuck in the floor.

### Movement/Positional Softlocks

  * **Out of Bounds Encounters:** If you are out-of-bounds ([Kalm Skip](/index.php?title=Kalm_Skip&action=edit&redlink=1 "Kalm Skip \(page does not exist\)"), Oceanfly, etc) and receive an encounter, the game will softlock.

### UI-Related Softlocks

  * **PHS Menu:** If you open this menu when less than three characters currently available, the game softlocks.
