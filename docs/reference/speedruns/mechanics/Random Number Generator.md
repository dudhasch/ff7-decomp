A [Random Number Generator](https://en.wikipedia.org/wiki/Random_number_generation "wikipedia:Random number generation"), or RNG, is a procedure that generates numbers that are meant to be unpredictable. Final Fantasy VII has many RNG implementations that are used by different modules.

## Non-RNG Randomness

Some "random" events in this game are determined without the use of a random number generator.

### IGT (In-Game Time)

  * The Mayor's Password is determined by total IGT seconds modulo 4.
  * The "Evil Flag" in Cait Sith's Slots limit break is determined by total IGT seconds.
  * The Battle Square reels are decided by total IGT seconds modulo 128.
