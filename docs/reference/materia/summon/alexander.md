# Alexander Materia

> *Summons Alexander*

## Overview

The only Holy-elemental summon. Devastating against undead enemies, and the Elemental Materia source for Holy.

## At a glance

| | |
| --- | --- |
| **Category** | [Summon Materia](README.md) (red) |
| **Element** | Holy |
| **Status** | -- |
| **AP to master** | 150,000 |
| **Castings per battle** | 1 per star (5 at master) |
| **Sell price** | 1 gil - Summon Materia can never be bought, and always sell for 1 gil regardless of level |
