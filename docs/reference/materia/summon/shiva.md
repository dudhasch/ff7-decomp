# Shiva Materia

> *Summons Shiva*

## Overview

The only Summon Materia obtained through the storyline, so every playthrough has one. Diamond Dust is ice-elemental damage to all enemies.

## At a glance

| | |
| --- | --- |
| **Category** | [Summon Materia](README.md) (red) |
| **Element** | Ice |
| **Status** | -- |
| **AP to master** | 50,000 |
| **Castings per battle** | 1 per star (5 at master) |
| **Sell price** | 1 gil - Summon Materia can never be bought, and always sell for 1 gil regardless of level |

- Under Junon - a gift from Priscilla. Appears in Priscilla's House instead if the Materia stock is full at that point.
