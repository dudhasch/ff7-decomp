# Summon Materia (red)

Grants the **Summon** command. A Summon Materia may be cast once per battle per star, so a mastered Materia allows five castings. Summon Materia can never be bought and always sell for 1 gil. Shiva is the only one obtained through the storyline.

Note the Materia's element does not always match its summon's element - Choco/Mog and Typhon are both Wind-elemental Materia whose attacks are not.
