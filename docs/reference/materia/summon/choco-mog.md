# Choco/Mog Materia

> *Summons Choco/Mog*

## Overview

The cheapest Summon to master and the only one that inflicts a status. Its Materia is Wind-elemental even though the summon attack is not, which makes it a Wind source for Elemental Materia pairings. One casting in sixteen calls Fat-Chocobo instead.
