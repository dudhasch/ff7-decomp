# Contain Materia

> *Equips "Contain" magic*

## Overview

Late-game elemental magic, one tier above the basic lines: Freeze (ice + Stop), Break (earth + Petrify), Tornado (wind + Confusion) and Flare (fire). Tornado is the game's only wind-elemental spell. Costly in MP and in stat penalties, but the highest-power elemental Materia available.
