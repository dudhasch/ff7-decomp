# Exit Materia

> *Equips "Exit" magic*

## Overview

Battle-removal magic. Escape ends the fight immediately with no EXP, AP or Gil. Remove deletes a single enemy from the battle and flags it as dead, yielding no Gil from that enemy - useful for thinning out dangerous groups.
