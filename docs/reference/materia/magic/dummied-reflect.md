# リフレク (Rifureku) - "Reflect" (dummied)

> **Unused.** This Materia exists in the game data but is never obtainable; it has no price and no location.

## Overview

An unused split of the Barrier line into a standalone Reflect/Wall Materia. Its level 3 grants nothing and its AP costs (360,000 and 420,000) are far beyond anything in the shipped game.

## In-game description (unused)

リフレクの魔法が使えるようになる。 (*Rifureku no maho ga tsukaeru yo ni naru.* - lit. "You become able to use Reflect magic.")
