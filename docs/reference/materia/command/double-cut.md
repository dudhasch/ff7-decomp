# Double Cut Materia

> *Attacks consecutively*

## Overview

2x-Cut performs two physical attacks in one turn; 4x-Cut performs four. Because each hit carries the weapon's full damage formula, 4x-Cut on a strong physical character rivals the best magic in the game.
