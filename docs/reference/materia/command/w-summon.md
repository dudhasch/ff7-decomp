# W-Summon Materia

> *Casts two Summon spells at once*

## Overview

Casts two summons in a single turn. Each casting still counts against the per-battle limit of the Summon Materia used, so it burns through low-level Summon Materia quickly.

## At a glance

| | |
| --- | --- |
| **Category** | [Command Materia](README.md) (yellow) |
| **Element** | Hidden (Command Materia have no element of their own) |
| **Status** | None - Command Materia carry no status traits for Added Effect |
| **Max level** | 2 |
| **AP to master** | 250,000 |
| **Buy price** | 1 gil |

## Stat changes

None.

## Levels

| Level | Command | AP to reach |
| --- | --- | --- |
| 1 | W-Sum. | 0 |
| 2 | MASTER | 250,000 |

## How to obtain

- Battle Square prize for 64,000 BP (after obtaining the Highwind)
