# Sense Materia

> *Equips "Sense" command*

## Overview

Displays an enemy's current and maximum HP/MP along with its elemental weaknesses. Fails against enemies with high enough level relative to the user.

## At a glance

| | |
| --- | --- |
| **Category** | [Command Materia](README.md) (yellow) |
| **Element** | Hidden (Command Materia have no element of their own) |
| **Status** | None - Command Materia carry no status traits for Added Effect |
| **Max level** | 2 |
| **AP to master** | 40,000 |
| **Buy price** | 1,000 gil |

## Stat changes

None.

## Levels

| Level | Command | AP to reach |
| --- | --- | --- |
| 1 | Sense | 0 |
| 2 | MASTER | 40,000 |

## How to obtain

- Sector 6 playground
- Initially equipped on Red XIII
- Bought at Junon (Part 1) and Kalm
