# W-Item Materia

> *Use two items at once*

## Overview

Uses two items per turn. Notorious for the item-duplication glitch: selecting a first item, then cancelling on the second, multiplies the first item's stock.

## At a glance

| | |
| --- | --- |
| **Category** | [Command Materia](README.md) (yellow) |
| **Element** | Hidden (Command Materia have no element of their own) |
| **Status** | None - Command Materia carry no status traits for Added Effect |
| **Max level** | 2 |
| **AP to master** | 250,000 |
| **Buy price** | 1 gil |

## Stat changes

None.

## Levels

| Level | Command | AP to reach |
| --- | --- | --- |
| 1 | W-Item | 0 |
| 2 | MASTER | 250,000 |

## How to obtain

- Winding Tunnel during "Mako Cannon Rampage". If missed, it can be dug up at Bone Village.
