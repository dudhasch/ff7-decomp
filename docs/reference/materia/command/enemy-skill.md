# Enemy Skill Materia

> *Equips "Enemy Skill" command*

## Overview

Final Fantasy VII's Blue Magic. The Materia learns an enemy ability permanently when a character wearing it is successfully hit by that ability. Unique among Command Materia: it cannot gain AP, cannot be mastered, never reproduces, and refuses to work with any Support Materia. There are exactly four in the game. See [the enemy skill list](../../spells/enemy-skill/) for all twenty-four skills.
