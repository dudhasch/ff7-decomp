# Manipulate Materia

> *Equips "Manipulate" command*

## Overview

Takes direct control of an enemy, letting the player use its own attacks. Essential for collecting Enemy Skills from enemies that never use them voluntarily - ten of the twenty-four skills are Manipulate-only.

## At a glance

| | |
| --- | --- |
| **Category** | [Command Materia](README.md) (yellow) |
| **Element** | Hidden (Command Materia have no element of their own) |
| **Status** | None - Command Materia carry no status traits for Added Effect |
| **Max level** | 2 |
| **AP to master** | 40,000 |
| **Buy price** | 10,000 gil |

## Stat changes

None.

## Levels

| Level | Command | AP to reach |
| --- | --- | --- |
| 1 | Manip. | 0 |
| 2 | MASTER | 40,000 |

## How to obtain

- Initially equipped on Cait Sith
- Bought at Fort Condor and Rocket Town (after obtaining the Highwind)
