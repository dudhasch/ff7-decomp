# Throw Materia

> *Equips "Throw" command*

## Overview

Throw hurls a weapon or a throwing item at an enemy - the weapon is lost permanently. Coin, at level 2, throws gil for damage proportional to the amount spent.

## At a glance

| | |
| --- | --- |
| **Category** | [Command Materia](README.md) (yellow) |
| **Element** | Hidden (Command Materia have no element of their own) |
| **Status** | None - Command Materia carry no status traits for Added Effect |
| **Max level** | 3 |
| **AP to master** | 60,000 |
| **Buy price** | 10,000 gil |

## Stat changes

| Stat | Change |
| --- | --- |
| Vitality | +1 |

## Levels

| Level | Command | AP to reach |
| --- | --- | --- |
| 1 | Throw | 0 |
| 2 | Coin | 45,000 |
| 3 | MASTER | 60,000 |

## How to obtain

- Initially equipped on Yuffie
- Bought at Fort Condor and Rocket Town (after obtaining the Highwind)
