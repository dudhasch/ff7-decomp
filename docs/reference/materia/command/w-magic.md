# W-Magic Materia

> *Casts two Magic spells at once*

## Overview

Replaces the Magic command with one that casts two spells per turn. Both spells are chosen before either resolves. A cornerstone of high-level play, but 250,000 AP to master.

## At a glance

| | |
| --- | --- |
| **Category** | [Command Materia](README.md) (yellow) |
| **Element** | Hidden (Command Materia have no element of their own) |
| **Status** | None - Command Materia carry no status traits for Added Effect |
| **Max level** | 2 |
| **AP to master** | 250,000 |
| **Buy price** | 1 gil |

## Stat changes

None.

## Levels

| Level | Command | AP to reach |
| --- | --- | --- |
| 1 | W-Magic | 0 |
