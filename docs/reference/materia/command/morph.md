# Morph Materia

> *Equips "Morph" command*

## Overview

Transforms a defeated enemy into an item instead of the usual drop. Damage is cut to 1/8, so Morph usually needs a dedicated setup. It is the only source of several key items, including the Guide Book and every Source item farmed in bulk.
