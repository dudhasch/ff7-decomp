# Deathblow Materia

> *Equips "Deathblow" command*

## Overview

A physical attack that always lands a critical hit (double damage) but has a reduced chance to connect at all. Pairs naturally with weapons that have poor accuracy but high power.

## At a glance

| | |
| --- | --- |
| **Category** | [Command Materia](README.md) (yellow) |
| **Element** | Hidden (Command Materia have no element of their own) |
| **Status** | None - Command Materia carry no status traits for Added Effect |
| **Max level** | 2 |
| **AP to master** | 40,000 |
| **Buy price** | 10,000 gil |
