# Mega All Materia

## Overview

An All Materia that needs no link and covers physical attacks and commands as well as magic. Limited by castings per battle rather than applying permanently.

## At a glance

| | |
| --- | --- |
| **Category** | [Independent Materia](README.md) (purple) |
| **Max level** | 5 |
| **AP to master** | 160,000 |

## Stat changes

None.

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Physical attacks, commands (Steal, Mug, Sense, Morph, D.blow, Manip.) and magic spells affect all enemies or allies at once. Once per battle. Spells incompatible with All are exempt. | 0 |
| 2 | Twice per battle. | 20,000 |
| 3 | Three times. | 40,000 |
| 4 | Four times. | 80,000 |
| Master | Five times per battle. | 160,000 |

## How to obtain

- Northern Cave
