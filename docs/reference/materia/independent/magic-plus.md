# Magic Plus Materia

## Overview

Raises the Magic stat that every spell and summon damage formula is built on.

## At a glance

| | |
| --- | --- |
| **Category** | [Independent Materia](README.md) (purple) |
| **Max level** | 5 |
| **AP to master** | 50,000 |

## Stat changes

None.

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Increases Magic by 10%. | 0 |
| 2 | By 20%. | 10,000 |
| 3 | By 30%. | 20,000 |
| 4 | By 40%. | 30,000 |
| Master | By 50%. | 50,000 |

## How to obtain

- Corel Valley
