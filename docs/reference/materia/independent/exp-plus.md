# EXP Plus Materia

## Overview

Affects only the character wearing it, not the party. The standard tool for catching up under-levelled party members.

## At a glance

| | |
| --- | --- |
| **Category** | [Independent Materia](README.md) (purple) |
| **Max level** | 3 |
| **AP to master** | 150,000 |

## Stat changes

| Stat | Change |
| --- | --- |
| Luck | +1 |

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | The wearer earns 1.5x EXP from battle. | 0 |
| 2 | The wearer earns 2x EXP. | 60,000 |
| Master | No further effect. | 150,000 |

## How to obtain

- Wonder Square prize (after Cloud and Tifa rejoin the party)
