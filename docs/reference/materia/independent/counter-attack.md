# Counter Attack Materia

## Overview

Free physical counters with no linking required. Distinct from the Support Materia named Counter - confusingly, the chocobo-race prize labelled "Counter" is this Materia.

## At a glance

| | |
| --- | --- |
| **Category** | [Independent Materia](README.md) (purple) |
| **Max level** | 5 |
| **AP to master** | 100,000 |

## Stat changes

None.

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | 20% chance of countering an attack with a physical attack. | 0 |
| 2 | 40% chance. | 10,000 |
| 3 | 60% chance. | 20,000 |
| 4 | 80% chance. | 50,000 |
| Master | 100% chance. | 100,000 |

## How to obtain

- Defeat the Materia Keeper in Mt. Nibel
- Prize from the chocobo races
