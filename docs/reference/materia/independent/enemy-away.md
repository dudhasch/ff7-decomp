# Enemy Away Materia

## Overview

The inverse of Enemy Lure. Invaluable when crossing long dungeons or grinding chocobo breeding without wanting fights.

## At a glance

| | |
| --- | --- |
| **Category** | [Independent Materia](README.md) (purple) |
| **Max level** | 3 |
| **AP to master** | 50,000 |

## Stat changes

| Stat | Change |
| --- | --- |
| Luck | +1 |

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Decreases the random encounter rate by 43.75%. | 0 |
| 2 | Decreases it by 87.5%. | 10,000 |
| Master | Decreases it by 87.5%. | 50,000 |

## How to obtain

- Chocobo racing prize
