# Independent Materia (purple)

Provides a support ability without needing to be linked to anything, and often a stat boost as well. Enemy Lure is the only Independent Materia with a stat penalty.

| Materia | Effect | Stat changes | AP to master |
| --- | --- | --- | --- |
| [Cover](cover.md) | 20% chance of intercepting an attack aimed at an ally. | Vitality +1 | 40,000 |
| [Chocobo Lure](chocobo-lure.md) | Chocobos can be encountered near chocobo tracks on the world map. | Luck +1 | 30,000 |
| [Long Range](long-range.md) | Attacks do full damage regardless of row, and can reach enemies normally out of melee range. | None | 80,000 |
| [Counter Attack](counter-attack.md) | 20% chance of countering an attack with a physical attack. | None | 100,000 |
| [Enemy Lure](enemy-lure.md) | Increases the random encounter rate by 43.75%. | Luck -1 | 50,000 |
| [Speed Plus](speed-plus.md) | Increases Dexterity by 10%. | None | 100,000 |
| [MP Plus](mp-plus.md) | Increases max MP by 10%. | None | 50,000 |
| [HP Plus](hp-plus.md) | Increases max HP by 10%. | None | 50,000 |
| [Luck Plus](luck-plus.md) | Increases Luck by 10%. | None | 100,000 |
| [Magic Plus](magic-plus.md) | Increases Magic by 10%. | None | 50,000 |
| [Gil Plus](gil-plus.md) | Earn 2x gil from battle. (Because of a bug this is always 2x, although one star was presumably intended to give 1.5x.) | Luck +1 | 150,000 |
| [Pre-Emptive](pre-emptive.md) | +6% chance of a pre-emptive strike. | Dexterity +2 | 80,000 |
| [EXP Plus](exp-plus.md) | The wearer earns 1.5x EXP from battle. | Luck +1 | 150,000 |
| [Enemy Away](enemy-away.md) | Decreases the random encounter rate by 43.75%. | Luck +1 | 50,000 |
| [Mega All](mega-all.md) | Physical attacks, commands (Steal, Mug, Sense, Morph, D.blow, Manip.) and magic spells affect all enemies or allies at once. Once per battle. Spells incompatible with All are exempt. | None | 160,000 |
| [HP<->MP](hp-mp.md) | Exchanges the character's HP and MP values. | None | 80,000 |
| [Underwater](underwater.md) | Removes the 20:00 time limit in the Emerald Weapon fight. | None | 0 |

See also: [all Materia](../README.md)
