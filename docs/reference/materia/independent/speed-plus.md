# Speed Plus Materia

## Overview

Raises Dexterity, which drives ATB fill rate and physical accuracy. One of the four "Plus" stat Materia.

## At a glance

| | |
| --- | --- |
| **Category** | [Independent Materia](README.md) (purple) |
| **Max level** | 5 |
| **AP to master** | 100,000 |

## Stat changes

None.

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Increases Dexterity by 10%. | 0 |
| 2 | By 20%. | 15,000 |
| 3 | By 30%. | 30,000 |
| 4 | By 40%. | 60,000 |
| Master | By 50%. | 100,000 |

## How to obtain

- Battle Square prize
