# Gil Plus Materia

## Overview

Doubles battle gil rewards from level 1 onward thanks to the bug, making the 80,000 AP level-up pointless.

## At a glance

| | |
| --- | --- |
| **Category** | [Independent Materia](README.md) (purple) |
| **Max level** | 3 |
| **AP to master** | 150,000 |

## Stat changes

| Stat | Change |
| --- | --- |
| Luck | +1 |

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Earn 2x gil from battle. (Because of a bug this is always 2x, although one star was presumably intended to give 1.5x.) | 0 |
| 2 | Earn 2x gil from battle. | 80,000 |
| Master | No further effect. | 150,000 |

## How to obtain

- Wonder Square prize (after obtaining the Highwind)
