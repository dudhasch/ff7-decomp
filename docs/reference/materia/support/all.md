# All Materia

## Overview

The most widely used Support Materia in the game. Single-target spells cast this way take a 1/3 damage penalty when aimed at all enemies; spells that already hit everything take no penalty. Healing the whole party with All-linked Restore is the standard party setup from the first disc onward.

## At a glance

| | |
| --- | --- |
| **Category** | [Support Materia](README.md) (blue) |
| **Max level** | 5 |
| **AP to master** | 35,000 |
| **Stat changes** | None - Support Materia never change stats |

Restore, Heal, Revive, Fire, Ice, Lightning, Earth, Poison, Gravity, Seal, Mystify, Transform, Time, Barrier, Destruct, Master Magic

## How to obtain

- Sector 7 Slums
- Shinra Bldg. (Floor 63)
- Initially equipped on Red XIII
- Cargo Ship
- Mt. Nibel
- Great Glacier
- Fort Condor shop (after obtaining the Highwind)
- Prize for Snowboarding Course B with 89+ points

## Note

Because of the *Master Command and Support Materia* glitch, a Support Materia linked to [Master Command](../command/master-command.md) applies its effect to every command the character can use - including plain Attack and Item.
