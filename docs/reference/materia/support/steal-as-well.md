# Steal as well Materia

## Overview

Folds a steal attempt into every use of the linked Materia, so a character can farm items without giving up their turn to the Steal command.

## At a glance

| | |
| --- | --- |
| **Category** | [Support Materia](README.md) (blue) |
| **Max level** | 2 |
| **AP to master** | 200,000 |
| **Stat changes** | None - Support Materia never change stats |

## Links to

All Magic and Summon Materia; Sense, Throw, Morph, Deathblow, Manipulate, Master Command

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Attempts to steal whenever the linked Materia is used. | 0 |
| 2 | No further effect. | 200,000 |

## How to obtain

- Da-chao Statue in Wutai

## Note

Because of the *Master Command and Support Materia* glitch, a Support Materia linked to [Master Command](../command/master-command.md) applies its effect to every command the character can use - including plain Attack and Item.
