# Support Materia (blue)

Modifies a Magic, Command or Summon Materia placed in a **linked** slot beside it. Support Materia are the only kind that never change the wearer's stats.

| Materia | Effect at level 1 | AP to master |
| --- | --- | --- |
| [Added Cut](added-cut.md) | Follows up use of the linked Materia with a physical attack, against the same target as the previous action. | 200,000 |
| [Added Effect](added-effect.md) | On a weapon: 20% chance per hit to inflict the linked Materia's status. On armor: grants immunity to that status. | 100,000 |
| [All](all.md) | Linked Magic Materia can target all allies or enemies once per battle. | 35,000 |
| [Counter](counter.md) | 30% chance of countering an attack with the linked Materia. | 100,000 |
| [Elemental](elemental.md) | Weapon takes on the linked Materia's element. Armor halves damage from that element. | 80,000 |
| [Final Attack](final-attack.md) | Uses the linked Materia when the wearer is killed. | 160,000 |
| [HP Absorb](hp-absorb.md) | When the linked Materia deals damage, the user recovers HP equal to 10% of it. | 100,000 |
| [Magic Counter](magic-counter.md) | 30% chance of countering an attack with the linked Magic Materia. | 300,000 |
| [MP Absorb](mp-absorb.md) | When the linked Materia deals damage, the user recovers MP equal to 1% of it. | 100,000 |
| [MP Turbo](mp-turbo.md) | Linked Magic or Summon deals 10% more damage and costs 10% more MP. | 120,000 |
| [Quadra Magic](quadra-magic.md) | Casts the linked Magic or Summon four times in succession at half damage each - 2x total damage for the normal MP cost. Usable once per battle. | 200,000 |
| [Sneak Attack](sneak-attack.md) | 20% chance to use the linked Materia the moment battle begins. | 150,000 |
| [Steal as well](steal-as-well.md) | Attempts to steal whenever the linked Materia is used. | 200,000 |
