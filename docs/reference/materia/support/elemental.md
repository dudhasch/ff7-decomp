# Elemental Materia

## Overview

Turns physical attacks elemental, or turns armor into elemental protection. At level 3 in armor it converts an entire damage type into healing. Pairing with a non-elemental Materia gives the Hidden element, which is almost always useless - the only enemy attack dealing Hidden damage is Ultimate Weapon's Ultima Beam.

## At a glance

| | |
| --- | --- |
| **Category** | [Support Materia](README.md) (blue) |
| **Max level** | 4 |
| **AP to master** | 80,000 |
| **Stat changes** | None - Support Materia never change stats |

## Links to

Fire, Ice, Lightning, Earth, Poison, Gravity, Choco/Mog, Shiva, Ifrit, Ramuh, Titan, Leviathan, Alexander, Phoenix, Typhon

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | Weapon takes on the linked Materia's element. Armor halves damage from that element. | 0 |
| 2 | Weapon as above. Armor nullifies that element. | 10,000 |
| 3 | Weapon as above. Armor absorbs that element (damage heals instead). | 40,000 |
| 4 | No further effect. | 80,000 |

## How to obtain

- Shinra Bldg. (Floor 62) - guess the mayor's password on the first try
- Mt. Nibel mako fountain
- Play Tifa's piano in Nibelheim with Tifa as party leader

## Note

Because of the *Master Command and Support Materia* glitch, a Support Materia linked to [Master Command](../command/master-command.md) applies its effect to every command the character can use - including plain Attack and Item.
