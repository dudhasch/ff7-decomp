# Added Effect Materia

## Overview

The two halves of this Materia are used for entirely different purposes. On armor it is one of the best defensive options in the game - linked to Hades it blocks eight statuses at once, and linked to Odin it blocks instant death.

## At a glance

| | |
| --- | --- |
| **Category** | [Support Materia](README.md) (blue) |
| **Max level** | 1 |
| **AP to master** | 100,000 |
| **Stat changes** | None - Support Materia never change stats |

## Links to

Poison, Seal, Mystify, Transform, Time, Destruct, Contain, Choco/Mog, Odin, Hades

## Levels

| Level | Effect | AP to reach |
| --- | --- | --- |
| 1 | On a weapon: 20% chance per hit to inflict the linked Materia's status. On armor: grants immunity to that status. | 100,000 |

## How to obtain

- Cave of the Gi. **Missable** if not picked up.

## Note

Because of the *Master Command and Support Materia* glitch, a Support Materia linked to [Master Command](../command/master-command.md) applies its effect to every command the character can use - including plain Attack and Item.
