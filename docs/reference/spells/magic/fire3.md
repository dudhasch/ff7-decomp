# Fire3

> *Fire element attack*

## Effect

High fire-elemental damage.

## Details

| | |
| --- | --- |
| **Category** | Attack magic |
| **Granted by** | [Fire Materia](../../materia/magic/fire.md) at level 3 |
| **MP cost** | 52 |
| **Spell power** | 64 |
| **Reflectable** | Yes |

## Damage

Flat-damage attack magic uses:

```
damage = (SpellPower / 16) * ((Level + MagicAttack) * 6)
```

With spell power 64, a level 50 caster with 150 Magic deals roughly **4800** damage before defense.
