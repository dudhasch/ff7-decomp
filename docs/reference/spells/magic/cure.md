# Cure

> *Restores HP*

## Effect

Heal a small amount of HP.

## Details

| | |
| --- | --- |
| **Category** | Restore magic |
| **Granted by** | [Restore Materia](../../materia/magic/restore.md) at level 1 |
| **MP cost** | 5 |
| **Spell power** | 5 |
| **Reflectable** | Yes |

## Healing

Restorative magic uses:

```
HP restored = (SpellPower * 22) + ((Level + MagicAttack) * 6)
```

With spell power 5, a level 50 caster with 150 Magic restores roughly **1,310** HP.
