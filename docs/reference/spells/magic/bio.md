# Bio

> *Poison element attack*

## Effect

Low poison-elemental damage. 48% chance of inflicting Poison.

## Details

| | |
| --- | --- |
| **Category** | Attack magic |
| **Granted by** | [Poison Materia](../../materia/magic/poison.md) at level 1 |
| **MP cost** | 8 |
| **Spell power** | 10 |
| **Reflectable** | Yes |

## Damage

Flat-damage attack magic uses:

```
damage = (SpellPower / 16) * ((Level + MagicAttack) * 6)
```

With spell power 10, a level 50 caster with 150 Magic deals roughly **750** damage before defense.
