# Bolt2

> *Lightning element attack*

## Effect

Moderate lightning-elemental damage.

## Details

| | |
| --- | --- |
| **Category** | Attack magic |
| **Granted by** | [Lightning Materia](../../materia/magic/lightning.md) at level 2 |
| **MP cost** | 22 |
| **Spell power** | 20 |
| **Reflectable** | Yes |

## Damage

Flat-damage attack magic uses:

```
damage = (SpellPower / 16) * ((Level + MagicAttack) * 6)
```

With spell power 20, a level 50 caster with 150 Magic deals roughly **1500** damage before defense.
