# Cure3

> *Restores HP*

## Effect

Heal a large amount of HP.

## Details

| | |
| --- | --- |
| **Category** | Restore magic |
| **Granted by** | [Restore Materia](../../materia/magic/restore.md) at level 4 |
| **MP cost** | 64 |
| **Spell power** | 130 |
| **Reflectable** | Yes |

## Healing

Restorative magic uses:

```
HP restored = (SpellPower * 22) + ((Level + MagicAttack) * 6)
```

With spell power 130, a level 50 caster with 150 Magic restores roughly **4,060** HP.
