# Quake3

> *Earth element attack*

## Effect

High earth-elemental damage.

## Details

| | |
| --- | --- |
| **Category** | Attack magic |
| **Granted by** | [Earth Materia](../../materia/magic/earth.md) at level 3 |
| **MP cost** | 68 |
| **Spell power** | 70 |
| **Reflectable** | Yes |

## Damage

Flat-damage attack magic uses:

```
damage = (SpellPower / 16) * ((Level + MagicAttack) * 6)
```

With spell power 70, a level 50 caster with 150 Magic deals roughly **5250** damage before defense.
