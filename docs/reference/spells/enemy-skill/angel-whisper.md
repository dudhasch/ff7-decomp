# Angel Whisper

> *Revives, restores HP and status to any one ally*

## Effect

Restores one target to maximum HP and cures Death, Sleep, Poison, Confusion, Silence, Slow, Stop, Frog, Small, Slow-numb, Petrify, Berserk, Paralysis and Darkness. If the target dies before the ability resolves it does not retarget. Cannot be reflected.

| **Reflectable** | No |
| **Permanently missable** | No |

## How to learn it

Learned from: **Pollensalta (Manipulate only)**

A character wearing an Enemy Skill Materia learns the skill the moment they are successfully targeted by it - whether or not they survive. The skill is lost if the party escapes the battle, and skills can never be learned in the Gold Saucer Battle Square.
