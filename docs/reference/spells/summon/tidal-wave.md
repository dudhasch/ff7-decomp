# Tidal Wave

> *Water Magic damage on all opponents*

## Effect

Water-elemental damage to all enemies.

## Details

| | |
| --- | --- |
| **Summon command** | Leviathan |
| **Granted by** | [Leviathan Materia](../../materia/summon/leviathan.md) |
| **MP cost** | 78 |
| **Spell power** | 75 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
