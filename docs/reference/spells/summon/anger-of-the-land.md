# Anger of the Land

> *Damages all opponents on the ground*

## Effect

Earth-elemental damage to all enemies.

## Details

| | |
| --- | --- |
| **Summon command** | Titan |
| **Granted by** | [Titan Materia](../../materia/summon/titan.md) |
| **MP cost** | 46 |
| **Spell power** | 33 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
