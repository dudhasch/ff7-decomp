# Phoenix Flame

> *Causes Fire Magic damage, and revives all allies*

## Effect

High Fire-elemental damage to all enemies, and resurrects dead allies.

## Details

| | |
| --- | --- |
| **Summon command** | Phoenix |
| **Granted by** | [Phoenix Materia](../../materia/summon/phoenix.md) |
| **MP cost** | 180 |
| **Spell power** | 60 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
