# Judgement Bolt

> *Lightning magic damage on all opponents*

## Effect

Lightning-elemental damage to all enemies.

## Details

| | |
| --- | --- |
| **Summon command** | Ramuh |
| **Granted by** | [Ramuh Materia](../../materia/summon/ramuh.md) |
| **MP cost** | 40 |
| **Spell power** | 30 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
