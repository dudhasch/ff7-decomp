# Black Cauldron

> *Changes status of all opponents*

## Effect

Non-elemental damage to all enemies, with a 100% chance of inflicting Poison, Confusion, Sleep, Silence, Small, Frog, Slow and Paralyzed on anything not immune.

## Details

| | |
| --- | --- |
| **Summon command** | Hades |
| **Granted by** | [Hades Materia](../../materia/summon/hades.md) |
| **MP cost** | 150 |
| **Spell power** | 90 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
