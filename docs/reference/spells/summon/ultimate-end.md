# Ultimate End

> *Extreme summoned monsters*

## Effect

Heavy non-elemental damage to all enemies, ignoring Magic Defense. The damage is the cumulative sum of thirteen separate hits.

## Details

| | |
| --- | --- |
| **Summon command** | Knights of Round |
| **Granted by** | [Knights of Round Materia](../../materia/summon/knights-of-round.md) |
| **MP cost** | 250 |
| **Spell power** | 80 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
