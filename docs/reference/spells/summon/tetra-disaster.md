# Tetra-Disaster

> *Causes [Fire/Ice/Lightning] magic damage*

## Effect

Fire-, Ice- and Lightning-elemental damage to all enemies.

## Details

| | |
| --- | --- |
| **Summon command** | Kujata |
| **Granted by** | [Kujata Materia](../../materia/summon/kujata.md) |
| **MP cost** | 110 |
| **Spell power** | 100 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
