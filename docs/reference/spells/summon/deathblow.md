# DeathBlow!!

> *Attacks all opponents. Sometimes causes [Stop]*

## Effect

15/16 of the time: non-elemental damage to all enemies with a 40% chance of inflicting Stop.

### Fat-Chocobo

1/16 of the time, Fat-Chocobo is called instead: non-elemental damage to all enemies. (spell power 20)

## Details

| | |
| --- | --- |
| **Summon command** | Choco/Mog |
| **Granted by** | [Choco/Mog Materia](../../materia/summon/choco-mog.md) |
| **MP cost** | 14 |
| **Spell power** | 16 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
