# Diamond Dust

> *Ice magic damage on all opponents*

## Effect

Ice-elemental damage to all enemies.

## Details

| | |
| --- | --- |
| **Summon command** | Shiva |
| **Granted by** | [Shiva Materia](../../materia/summon/shiva.md) |
| **MP cost** | 32 |
| **Spell power** | 24 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
