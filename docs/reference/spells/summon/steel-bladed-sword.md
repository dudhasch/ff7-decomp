# Steel Bladed Sword

> *Slashes all opponents*

## Effect

If the target is not immune to instant death: instantly kills all enemies, with 92% success.

### Gunge Lance

If the target is immune to instant death, Gunge Lance is used instead: non-elemental damage to a single target. (spell power 78)

## Details

| | |
| --- | --- |
| **Summon command** | Odin |
| **Granted by** | [Odin Materia](../../materia/summon/odin.md) |
| **MP cost** | 80 |
| **Spell power** | 0 |

## Castings per battle

A Summon Materia may be used once per battle per star: a level 3 Materia allows three castings. [Master Summon](../../materia/summon/master-summon.md) removes the limit entirely - only MP constrains it.
